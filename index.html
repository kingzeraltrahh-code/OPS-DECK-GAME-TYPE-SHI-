What this actually is

This page is a generator + dashboard for you as GM. It does not play the game for you and it doesn't talk to Discord directly. Its job is: roll up a scenario, a map, an encounter, and loot for you in one click, keep track of the table's state (players, HP, turn order, what's been found), and give you a place to jot down what actually happens. Dice are still rolled in Discord with Avrae — you type the results back in here.

The three game types

The Heist — infiltrate a target, grab an objective, get out. Haunted House — survive/escape/uncover the truth in a location with a threat in it. World Collapse — a survival scenario after some kind of disaster. Click a card at the top to pick one before generating; each has its own word pools for targets/threats/loot/enemies so the flavor stays consistent.

Difficulty

The Easy / Normal / Hard / Deadly toggle (top bar) controls how many enemies spawn, how much HP they have, whether a boss shows up, and how dangerous the starting SECURITY/DREAD/STABILITY meter reads. It only applies the next time you hit Generate Game — changing it mid-game doesn't retroactively touch the current encounter.

Generate row

  • Seed box — leave blank for a random game. Every generated game shows its seed next to SEED at the top; paste that seed back into this box before hitting Generate to reproduce the exact same scenario/map/encounter later. If you don't touch the box, Generate always rolls fresh — it won't accidentally repeat itself.
  • 🎲 Generate Game — rolls a brand new scenario, map, encounter, and loot list together. Resets turn order.
  • 🔄 Regenerate Scenario — rerolls only the target/objective/complication/secret and danger meter. Keeps your current map, enemies, and loot untouched.
  • 🗺️ Regenerate Map — rerolls only the map for whichever floor tab is currently active. Keeps the scenario. Also reshuffles which rooms enemies are standing in and rebuilds the loot list to match the new rooms.
  • ✎ Customize Word Lists — lets you rewrite the pools the generator draws from (targets, threats, loot, enemy names, boss names, etc.), one line per entry. Pick a game type card first, open this, choose a category, edit the list, Save. Reset to Default clears your override. Your custom list is used from then on for that game type until you reset it.
  • 💾 Save Game / 📂 Load Game — down in the Save/Load panel: Generate Save Code turns your whole current state (scenario, map, floors, players, enemies, loot, turn order) into a text blob you can paste somewhere safe; Load takes that blob back and restores everything exactly.

Host view vs Player view

Toggle top-right. Host view shows you everything: the GM secret, every room's loot/events/secret flag, enemy positions, locked doors. Player view hides all of that and fogs any room you haven't clicked to reveal yet — this is the view you should have up if you're sharing your screen with the table.

Mission Briefing panel

Shows the generated scenario fields, the danger meter, and (host view only) the GM secret. Click directly on any field's text (or the secret) to type over it — everything the generator picks is a first draft, not final. The 🖨️ Print button builds a clean printable sheet (scenario, room list, players, encounter, loot) and opens your browser's print dialog — save as PDF from there if you want a physical or digital handout.

Ops Map panel

  • Floor tabs sit above the map. + Add Floor generates a second connected map (for multi-level scenarios) and logs a flavor line about stairs connecting them.
  • In host view, click any room to reveal it — that's the only thing that reveals a room; nothing happens automatically. Once revealed, it also shows up unfogged in Player view.
  • Icons in a room: 🎁 loot, ⚡ event, ⚑ secret (host only), ⚔ + a number = live enemies posted there (host only), 🔒 on a connecting line = locked door, 📝 = you've added a note to that room.

Room Notes panel

Pick any room from the dropdown, write whatever actually happened there (an Avrae roll result, an ambush, a ruling you made), hit Save Note. It shows up as a 📝 tag on the map. Toggle Locked Door flips whether that room's connecting door is locked, any time.

Loot & Inventory panel

Auto-populated from whatever loot the map generator scattered around (rebuilds when you regenerate the map or add a floor). Check a box to mark something collected — it strikes through. You can also add your own items by hand with an optional source note.

Players panel

Type a name, pick a class from the dropdown, hit Add. + tag on a player row lets you flag status effects (Hidden, Injured, Poisoned, Down, Restrained, Inspired) — click a tag to remove it. Remove a player with the ✕.

    • Turn Order panel

    🎲 Roll Initiative rolls a d20 for every current player and every current enemy and merges them into one sorted list. ⏭ Next Turn steps through it and highlights whoever's up, looping back to the top after the last one.

    Enemies / NPCs panel

    Enemies spawn automatically every time you Generate Game (count and HP scale with Difficulty; on Hard/Deadly there's a chance one is a 👑 boss with much higher HP). Each shows which room it's posted in. 🎲 Reroll Encounter scraps the current enemies and rolls a fresh set without touching the scenario or map. You can also add one manually (name + starting HP). Each enemy row has a damage/heal input — type an amount, hit − Dmg or + Heal, and its HP bar updates. Dropping an enemy to 0 HP doesn't remove it automatically — it just stops counting toward that room's ⚔ badge on the map. Once it's actually dead and you're done with it, remove it with the ✕ so it stops cluttering the Enemies panel and turn order.

    Roll Resolution panel

    Set a DC, hit Request Roll — this pulls in whoever's currently in the turn order (or your player list, if no turn order yet) and gives each a row. 📋 Copy for Avrae copies a ready-to-paste !r 1d20+MOD dc <DC> command for Discord. As each player calls out their Avrae result, type their natural d20 roll and their modifier into that row, then hit Resolve Rolls — it works out success/fail against the DC, and a natural 20 or 1 is automatically flagged as a crit.

    Activity Log panel

    Everything the tool does — reveals, damage, rolls, joins — logs itself here automatically with a timestamp. There's also a plain text box at the top of the log so you can type in anything that happened in your own words, independent of the automated entries — useful for narrating outcomes that came from an Avrae roll rather than the built-in roll resolver.

    Good to know / limitations

    • Nothing auto-saves. This all lives in your browser tab only. Closing the tab or refreshing wipes everything unless you clicked Generate Save Code first and kept the text somewhere.
    • No live sync between screens. If your players want to see the map, you either share your screen (in Player view!) or read it out to them — there's no server, so a second device won't see your changes.
    • Revealed rooms can't be re-fogged. Once you click a room to reveal it, there's no button to hide it again in Player view — treat revealing as a one-way action.
    • Difficulty isn't retroactive. Changing it only affects the next full Generate Game, not the encounter you're currently running.
    • Print grabs whatever you're looking at. If you're in Player view when you hit 🖨️ Print, the secret and hidden room contents won't be on the sheet. Switch to Host view first if you want the full GM copy.
    • Regenerating a map on Floor 2+ reshuffles that floor's rooms/loot, but currently-placed enemies only get reassigned to new rooms automatically when you regenerate Floor 1 — on other floors, re-post them yourself if the layout changed a lot.
